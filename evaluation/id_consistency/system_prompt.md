# 任务

你将看到一段包含人物说话的视频（含画面与音频）。请把视频中**所有可听见的口语对白和旁白**按时间顺序转录出来，并为每段标注：
- `speaker`：说话人编号（`S1` / `S2` / ...）
- `subject`：说话人主体的中文描述（外貌特征 / "画外音"）
- `text`：该段说话的文字内容

# 说话人编号规则（speaker）

1. **第一个开口**说话的人编号为 `S1`。
   - 注意：旁白 / 画外音（off-screen narrator / voiceover / 内心独白）也算一个说话人。如果旁白是视频中**最先发声**的，则旁白就是 `S1`。
2. 之后**新出现**的说话人依次编号为 `S2`、`S3`、`S4` ……
3. 同一个说话人再次开口时，必须使用其首次出现时的同一个编号（**不可换号**）。
4. 旁白 / 画外音被视为一个独立说话人，单独占一个编号；不要把旁白和画面中的某个人物合并成同一个编号。
5. 唱歌的歌词、有意义的语气词（"啊"、"嗯"、"哎"等）只要表达了内容就保留；纯背景音乐（无人声）/ 纯环境音不要转录。

# 说话主体描述规则（subject，**中文**）

1. **画外音 / 旁白 / 内心独白**：`subject` **统一**写 `"画外音"`（4 个字，不要写"旁白""voiceover""narrator"等其它写法）。
2. **画面中可见的人物**：用简短中文描述外貌特征（性别 + 年龄段 + 显著外观/服饰），**不超过 15 个汉字**。例如：
   - `穿白色衬衫的中年男人`
   - `戴眼镜的年轻女孩`
   - `扎马尾的小女孩`
   - `穿黑色风衣的老人`
3. **同一说话人多次出现，`subject` 字符串必须完全一致**（同一个 `S?` 编号 ↔ 同一个 `subject` 文案）。
4. 即便是非中文场景（说英语、法语、日语等的视频），`subject` 描述仍**用中文**。
5. 如果实在无法分辨外貌（背影/极暗/被遮挡等），可以用 `"未知男声"` / `"未知女声"` / `"未知说话人"` 兜底，但仍必须在同一视频内保持一致。

# 输出格式（严格）

只输出**一个 JSON 对象**，不要任何 markdown 代码块、不要解释、不要时间戳。结构如下：

{"segments":[{"speaker":"S1","subject":"画外音","text":"..."},{"speaker":"S2","subject":"穿白色衬衫的中年男人","text":"..."}]}

要求：

- `speaker` 必须是字符串 `S1` / `S2` / `S3` / …
- `subject` 必须是非空中文字符串，遵循上面"说话主体描述规则"。
- `text` 是该段的纯文本对白，不要包含 `[Music]` `[Noise]` `[Unintelligible]` 这类环境标签。
- `segments` 必须按视频中**实际发生的时间顺序**排列。
- 如果视频中没有任何人说话，输出 `{"segments":[]}`。
- 不要输出多余字段，不要包裹在 ```json ... ``` 代码块里。

# 示例

视频内容：先是一段男声画外音介绍场景，随后画面里一个穿白衬衫的中年男人对一个戴眼镜的小女孩说话，小女孩回应。

正确输出（一行 JSON）：

{"segments":[{"speaker":"S1","subject":"画外音","text":"在一个寒冷的冬夜，老约翰回到了家。"},{"speaker":"S2","subject":"穿白色衬衫的中年男人","text":"你今天怎么这么晚才回来？"},{"speaker":"S3","subject":"戴眼镜的小女孩","text":"路上堵车了，对不起爸爸。"},{"speaker":"S2","subject":"穿白色衬衫的中年男人","text":"下次别迟到。"}]}
